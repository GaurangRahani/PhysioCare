PhysioCare
Complete UX Flow Document
Version 1.0 — Every Screen, Every Role, Every Flow
0. How to Read This Document
This document walks through every screen in PhysioCare, organized by role: Authentication (shared), Receptionist, Doctor, Patient, and Admin. Each screen includes a visual mockup, a description of what the user is doing, and the API/backend logic the screen depends on, so the UX and the data model stay traceable to each other.
Screens are numbered sequentially across the whole document so they can be referenced unambiguously during development and QA.
0.1 Roles Covered
Shared — Login, Self-Registration, Password Setup, Password Reset
Receptionist — Dashboard, Booking (new and existing patient), Payment Collection, Patient Search/Registration, Calendar Management
Doctor — Dashboard, Patient Clinical View, Consultation, Treatment Plan Builder, Exercise Library, Discharge
Patient — Dashboard (Today), Exercise Logging, Appointments, Self-Booking & Payment, Invoices, Profile, History
Admin — User Management, Role Assignment, System Overview
1. Authentication — Shared by All Roles
Every role lands on the same login page. After authentication, the frontend reads the user's role from the users table and routes to the correct dashboard.

Login is handled by Clerk's React SDK embedded on this page. PhysioCare's frontend never touches the password directly.

The patient's entire daily interaction is designed around one question: what do I need to do today? Everything else — appointments, invoices, history — is one tap away but never the default screen.

7. End-to-End Flow at a Glance
How the four roles connect across one full patient journey, from first booking to discharge:
Receptionist or Patient books an appointment (Screens 6-12 or 27-29) -> payment confirmed -> appointment status becomes scheduled
Patient arrives -> Doctor reviews history (Screen 14-15) -> creates consultation (Screen 16)
Doctor builds or modifies the treatment plan (Screens 17-20) -> background job generates the patient's daily schedule
Patient logs exercises daily from home (Screens 24-26) -> compliance counters and pain trends accumulate automatically
Patient returns for follow-up -> Doctor sees full compliance and pain history instantly (Screen 14) -> modifies plan or discharges (Screen 23)
Discharged patient retains full read access to history (Screens 31-32) and can be re-activated on a future visit with nothing lost
